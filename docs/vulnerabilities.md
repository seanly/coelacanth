# 3.76.1-02 公开漏洞清单

工程版本是 `3.76.1-02`，在基线构建号上递增一位。代码基线是 tag `release-3.76.1-01`（2025-01-23）。这条 OSS 线的 sunset 日期是 2026-07-07，Sonatype 不再为它发布修复。下面的受影响范围仍按官方 3.76.1 计。

下面是截至 2026-10-23、Sonatype 公告里受影响范围覆盖 3.76.1 的产品漏洞。CloudRepo 同日把其中 30 条标在 3.76.1 上。清单只记录编号、前提、影响和官方修复版本，不写利用方式。官方修复都在更晚的 Community Edition / Pro 版本里。本文件只做记录，不移植补丁。

从本 tag 编译出的发行物只有 Maven、Raw、APT。官方 3.76.1 OSS 安装包另外带有未公开源码的格式插件，因此有两条漏洞只适用于那个安装包。
